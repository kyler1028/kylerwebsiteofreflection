Workshop: Web-scraping

In Week 3, the workshop focused on web scraping and how to collect data from websites. We learned that web scraping allows us to extract information from web pages, such as programme titles, descriptions and online content. This data can then be used for digital media research and analysis.

During the workshop, we were introduced to different web scraping tools, including WebScraper.io and Python. We explored how to use the WebScraper.io Chrome extension to select information from a webpage and export the collected data as a CSV file. We also learned about using Python in Google Colab to collect information from websites such as BBC iPlayer.

Overall, this workshop gave me a basic understanding of web scraping and its potential uses in digital media research. It also made me think more carefully about how we collect and interpret online data.
